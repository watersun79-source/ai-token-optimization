1. 의미 있는 AI 프로젝트·기억 유지 작업을 시작할 때 색인 → 프로토콜 → 색인의 최신 보고서 → 관련 Slack 기록을 실제로 읽는다. 이미 읽은 같은 문서를 한 작업 안에서 이유 없이 반복 조회하지 않는다.
2. 사용자 최신 지시와 날짜가 명시된 최신 관찰을 우선한다. 과거 보고서의 “현재”는 그 보고서 작성 시점이다. 필요하면 원래 시스템을 읽기 전용으로 확인한다. 상태 복원에 불필요한 예전 테스트·모델 검토를 다시 실행하지 않는다.
3. 완료·부분 완료·차단·미확인·실패를 구분하고, 영향이 큰 미완료 작업을 진행한다. 공급자 생성 API·구매·업그레이드는 금지한다. 무료 소비자 웹 검토도 실제 응답이 있을 때만 사용 실적으로 기록한다.
4. 저장 실패·도구 부재·접근 실패가 있으면 해당 항목을 미완료로 남긴다. 예전 접근 장애를 재확인 없이 현재 장애로 반복하지 않는다. 실제 노출된 도구만 사용한다.

## 적용과 완료 기준

2026-10-19 적용 확인: 앞선 적용에서는 ChatGPT와 데스크톱·웹 동기화 Codex 맞춤 지침에 동일한 1,133 UTF-16 단위 본문을 저장·재조회했다. 이후 사용자가 새 프롬프트를 요청하고 ‘진행’한 뒤 23:55~23:57 새 본문 1,290 단위를 확인했다. ChatGPT에서는 이미 저장된 새 값을 직접 읽어 파일과 전체 문자열 일치를 확인했으며 이번 root는 쓰지 않았다. Codex에서는 이전 값을 로컬 백업하고 새 본문을 저장한 뒤 새로고침·다시 열기에서 전체 문자열 일치와 저장 버튼 비활성을 확인했다. ChatGPT 메모리 스위치는 기존 ON이며 로컬 features.memories·generate_memories·use_memories도 앞선 조회에서 true였다. 기억 설정 자체는 바꾸지 않았다. 앞선 분리 문맥 복원 시험과 이번 지침 저장 재조회는 서로 다른 검증이다.

2026-10-20 병렬 협동 적용 확인: 사용자의 Gemini·Claude 병렬 협동 지시에 따라 무료 웹의 동일 자료 독립 검토 2개와 교차 검토 2개를 실제로 받았다. 양쪽 생성 중 표시와 전송 시각을 직접 읽어 실행 겹침을 확인했다. 이를 반영한 현재 맞춤 지침 본문은 1,477 UTF-16 단위이며 ChatGPT·Codex에 저장한 뒤 새로고침·재열기에서 기대 본문 전체 문자열 일치와 저장 버튼 비활성을 확인했다. 정규 지침·표시본을 같은 내용으로 유지한다. 모델 간 동의는 사실 검증을 대신하지 않으며 승인 범위·원문·관찰 시각·미검증을 구분한다. 최초1133·후속1290과 당시 분리 복원6/6은 과거 증거로 보존하며 이번 새본문의 복원 재시험이나 정규 무인 자동 저장 성공으로 표시하지 않는다. [최신 병렬 협동 재분석](ai-parallel-review-2026-10-20.md)을 먼저 읽는다.

기억 기능 활성화, 맞춤 지침 저장, 외부 기록 조회, 격리된 문맥에서의 복원 검증은 서로 다른 확인 항목이다. 설정 화면에서 저장된 값을 다시 읽기 전에는 설정 적용 완료라고 하지 않는다. 로컬 Codex 기억 생성은 백그라운드 작업이며 즉시 저장이나 모든 대화의 전체 복원을 보장하지 않는다.

필수 지침은 맞춤 지침/AGENTS.md와 정규 문서로 연결하고, 프로젝트 사실은 최신 색인에서 읽는다. ChatGPT 웹의 기억과 로컬 Codex의 기억 저장소는 구분한다. 연결 도구가 없는 대화의 외부 기록 조회까지 완료됐다고 주장하지 않는다.

복원 검증은 대화의 과거 내용을 제공하지 않은 별도 에이전트에게 시작 주소만 주고, 최신 보고서·결정·제약·다음 작업을 출처와 함께 복원하게 한다. 이것은 실제 외부 기록 복원 시험이며 모든 ChatGPT 새 채팅의 자동 실행을 보장하는 시험은 아니다.

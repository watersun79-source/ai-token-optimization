# AI BOT v8.1 — Offline SHA-bound unified evidence

This isolated prototype unifies the local 100-rule swarm with all four verifier
languages without external model calls, cloud deployment or ChatGPT task changes.

- Read pre-existing Python/Java/JS \`runtime_proof.json\` and require
  \`runner.read_runtime_receipt()\` to verify 24-hour freshness, source hashes,
  input hashes and valid counts.
- Compile C11 with strict gcc flags in a disposable temporary directory, then
  execute against the *same* 20-case fixture used by Java/JavaScript.
- Run FAST 20 and FULL 100 local roles. Compare each to the independent serial
  oracle, and reject fail, unknown, spoofed bool or inconsistent SHA.
- Print a canonical \`R16_V81_UNIFIED_EVIDENCE=...\` JSON line with the 83
  successful fixture/check counts and immutable SHA-256 source fingerprint.
- Emit \`BLOCKED\` and a sanitized failure reason if anything is absent or
  mismatched. No secret or full tool output is reflected.
- \`GITHUB_RUN_ID\`, \`GITHUB_SHA\`, \`GITHUB_EVENT_NAME\` are self-reported CI
  environment data. The receipt is not officially attested until a separate
  GitHub API readback verifies the matching run, HEAD, jobs and logs.
- No ChatGPT official native per-run ledger or same-run GitHub/Slack tool-call
  attestation is available here. Their status always remains UNVERIFIED.

The isolated workflow performs this step after its existing individual
language and swarm checks. It does **not** modify the production hourly :15
workflow, ChatGPT :00 task, Activepieces or Slack.

Run from \`experiments/r16-bot-runtime\` after \`measure_runtime.py\`:

\`\`\`sh
python3 -m unittest -q test_v81_unified_evidence
python3 v81_unified_evidence.py
\`\`\`

All offline receipts are local, synthesized or generated by the CI job itself;
none authenticates an external generative agent or native scheduled execution.

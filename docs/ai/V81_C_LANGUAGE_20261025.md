# AI BOT v8.1 — C11 as fourth offline verification language (isolated)

Scope: \`ai/r16-v81-fast-full-ci-20261024\` only. This is not a native ChatGPT scheduler deployment or independent LLM agent.

## Language selection
- Python: role coordination, test orchestration, data parsing, fail-closed reporting.
- Java: independent strict timestamp oracle.
- JavaScript (Node.js): independent strict timestamp oracle.
- **C11 (GCC): new independent strict timestamp oracle**, using the exact same \`utc_strict_oracle_cases.tsv\` fixture as Java and JavaScript; covers timestamps, Gregorian leap dates, fractional seconds 1–9, UTC offsets up to ±18:00, and malformed/unicode characters.
- Bash: already used as CI orchestration glue; not another model/runtime.
- C++, Rust, and Go: deferred because they currently add dependency maintenance without a distinct verified goal. Add only on evidence of need.

## Boundaries
The established Python/Java/JavaScript 63-test receipt remains unchanged. The C oracle adds 20 shared test cases and 8 Python-led C-specific safety regressions in the **isolated full-regression job**, yielding 83 independent fixture/test-case executions across the four language paths when all jobs succeed. Do not confuse these with 83 real agent/model instances.

C binary is compiled into GitHub runner temporary storage; it is not checked into GitHub or deployed to Activepieces. Compiler errors, failed oracle cases, or malformed input fail the job. No provider API, payment, credentials, main-branch or existing :00/:15 schedule changes.

# AI 프로젝트 — 모든 대화와 예약에 적용할 실행 표준 (2026-10-21)

## 최상위 사용자 요청
새 채팅·기존 채팅·매시간 AI 예약에서 가능한 경우 동일한 **실행 우선** 방식으로 작업한다. 상태보고만 반복하는 대신 **검증 가능한 기존 해결책을 찾고 직접 적용·테스트·재검증·기억 저장까지 마친다**. 사용자 최신 지시가 오래된 외부 기록보다 우선하며, 플랫폼이 지원하지 않는 작업은 성공이라고 주장하지 않는다.

## 고정 작업 순서
1. **복원·현재 상태 확인**: 대화와 연결된 최신 원본만 간결히 읽는다. 기존에 통과한 검사는 변경이 없으면 반복하지 않는다.
2. **분석·우선순위**: 재현 가능한 실제 문제, 기대 목표, 영향 범위, 비용/위험을 확인한다. 다음 목표를 매 실행에서 정한다.
3. **기존 구현 조사**: 인터넷·GitHub에서 검증된 오픈소스·공식 문서·공개 CI/벤치마크·다른 사람의 구현을 먼저 찾는다. 라이선스·최신성·보안·무료 여부·운영 호환성을 확인한다. 설치하지 않은 upstream 패키지는 '설계 참고'로만 기록.
4. **실행**: 허용된 도구로 안전한 최소 코드·지침·운영 변경을 실제 적용한다. 실패 시 진단→수정→재시도→재검증하되 정책 거절/안전 검사 차단은 우회·맹목 재시도하지 않는다. 독립 작업은 가능한 경우 병렬 진행한다.
5. **검증**: 로컬 회귀→GitHub Actions·실행 원본 로그→변경 파일 SHA·상태·원본 재조회. 테스트 결과를 비운영/운영, 직접/정규 예약으로 구별하고 존재하지 않는 ID·수치·성공을 만들지 않는다.
6. **지속 기록**: 승인된 범위에서 GitHub 색인·프로토콜/보고서, 지정 Slack 스레드, Activepieces 검색 인덱스를 필요 최소량 갱신하고 독립 조회한다. 기록 실패 시 원인을 숨기지 않으며 다른 저장소로 우회하지 않는다.
7. **보고·다음 목표**: 한눈에 보이는 표·상태 그래프·필요시 원터치 명령. 실제 완료/부분/차단/미검증 4분류, SHA·공식 실행 ID·테스트 수·변경 파일·관련 링크와 미해결 목표만 간결하게 보고한다.

## 계정 메모리·맞춤형 지침의 적용 범위
이 파일과 GitHub·Slack·Activepieces 기록은 **외부 지속 기억**이고, ChatGPT 계정의 **메모리 요약 UI를 자동 편집하는 것이 아니다**. 제품 메모리 요약은 비동기일 수 있고, 사용자는 `설정 → 개인화 → 메모리 요약 → 관리`에서 검토·변경 요청할 수 있다. 모든 새/기존 채팅에서 동일하게 수행하려면 사용자가 아래 요약 프롬프트를 ChatGPT **맞춤형 지침**에 저장해야 한다. 연결 도구 접근/권한과 실행 환경에 따라 실제 수행 가능 범위는 달라질 수 있다.

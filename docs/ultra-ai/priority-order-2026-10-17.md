# ULTRA AI 우선순위 — 2026-10-17

## 최우선 목표: GitHub + Slack 기반 ChatGPT 기억 유지·최적화
1. 매 작업 시작 시 GitHub의 canonical memory/progress 문서를 먼저 읽고, 필요한 Slack 기록을 검색한다.
2. 작업 종료 시 결정사항, 진행 상태, 검증 증거, 실패/미확인 항목, 다음 목표를 GitHub 테스트 브랜치에 기록한다.
3. 요약/링크를 Slack 운영 기록에도 남긴다. 메시지 전송 성공과 검색/재조회 확인은 구분한다.
4. 다음 작업은 마지막 미완료 목표부터 이어간다. 기존 기록을 덮어쓰지 말고 순차적으로 갱신한다.
5. ChatGPT 메모리와 외부 기록은 동일하지 않다. GitHub/Slack이 모든 채팅에 자동 주입된다고 가정하지 말고, 작업 시작 때 실제로 읽어야 한다.

## 두 번째 목표: Gemini + Claude 무료 협업
1. 먼저 소비자용 웹앱 무료 경로를 확인하고, 가능하면 브라우저에서 직접 사용한다.
2. API 호출은 무료 한도/비용 조건이 명확히 확인되기 전까지 실행하지 않는다. 유료 호출, 결제, 업그레이드는 금지.
3. Gemini/Claude 응답은 실제로 받은 경우에만 협업 성공으로 기록한다. 연결 상태나 모델 목록 조회만으로 생성 성공을 주장하지 않는다.
4. 브라우저 접근이 막히면 정확한 오류와 필요한 복구 작업을 기록하고, API로 우회하지 않는다.

## 보호 조건
- 기존 매시간 정각 Asia/Seoul 예약과 운영 Activepieces 플로우는 수정/중지하지 않는다.
- 테스트는 별도 브랜치/비운영 테스트 환경에서만 한다.
- 비밀키/토큰은 기록하지 않는다.
- 모든 결과는 실행 증거, 미확인 사항, 다음 단계로 나눠 보고한다.

## 현재 상태
- GitHub 읽기/쓰기/재조회는 이전 테스트에서 성공.
- Slack 메시지 전송은 이전 테스트에서 링크를 반환했지만 검색을 통한 재조회는 미확인.
- Gemini/Claude 웹앱 사용은 브라우저 컨텍스트 오류로 실제 모델 응답 0건.
- 생성 API 호출 0회, 유료 API 호출 0회, 운영 플로우/예약 변경 0건.

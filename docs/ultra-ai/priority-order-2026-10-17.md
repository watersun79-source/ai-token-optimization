2. 작업 종료 시 결정사항, 진행 상태, 검증 증거, 실패/미확인 항목, 다음 목표를 GitHub 테스트 브랜치에 기록한다.
3. 요약/링크를 Slack 운영 기록에도 남긴다. 메시지 전송 성공과 검색/재조회 확인은 구분한다.

5. ChatGPT 메모리와 외부 기록은 동일하지 않다. GitHub/Slack이 모든 채팅에 자동 주입된다고 가정하지 말고, 작업 시작 때 실제로 읽어야 한다.

## 두 번째 목표: Gemini + Claude 무료 협업
1. 먼저 소비자용 웹앱 무료 경로를 확인하고, 가능하면 Gemini와 Claude를 각자의 공식 앱/웹사이트에서 직접 사용한다.
2. API 호출은 무료 한도/비용 조건이 명확히 확인되기 전까지 실행하지 않는다. 유료 API 호출, 결제, 업그레이드는 금지.
3. 사용자가 지정한 예외: 서비스가 유료를 요구하면 API를 사용하지 말고, ChatGPT가 브라우저에서 Gemini/Claude 소비자용 앱을 직접 열어 무료 접근 가능 여부를 확인하고 사용을 시도한다. 로그인·CAPTCHA·브라우저 권한 등 사용자 개입이 필요하면 그 지점에서 막힌 사실을 보고하고, 접근했다고 꾸미지 않는다.
4. Gemini/Claude 응답은 실제로 받은 경우에만 협업 성공으로 기록한다. 연결 상태나 모델 목록 조회만으로 생성 성공을 주장하지 않는다.
5. 브라우저 접근이 막히면 정확한 오류와 필요한 복구 작업을 기록하고, API로 우회하지 않는다.
